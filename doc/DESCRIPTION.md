# Resend

Resend is the email API for developers: send transactional and marketing
email from your apps via a simple REST API. This YunoHost package does NOT
run Resend locally — it installs a portal tile + nginx 302 quicklink to
`https://resend.com/` so the service is one click from your YunoHost
dashboard.

Use it when you have a Resend account (or plan to) and want it reachable
from your portal alongside self-hosted apps.
